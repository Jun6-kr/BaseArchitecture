# 알고리즘 질답과 오답 포인트

## 1. 분석과 재귀

### Q1. 시간 복잡도와 공간 복잡도는 무엇인가?

**답변**

입력 크기 n이 증가할 때 필요한 연산 수와 추가 메모리가 어떤 비율로 증가하는지를 나타낸다. 하드웨어에서 잰 절대 시간과 달리 성장률을 비교한다. 최악·평균·최선 중 어떤 경우를 분석하는지도 명시해야 한다.

**오답 포인트**

- O 표기법은 정확한 실행 시간이 아니다.
- 입력 크기와 입력 분포를 말하지 않은 성능 주장은 불완전하다.

### Q2. O, Ω, Θ 표기법의 차이는?

**답변**

O는 점근적 상한, Ω는 점근적 하한, Θ는 상한과 하한이 같은 긴밀한 경계를 뜻한다. 예를 들어 병합 정렬의 시간은 Θ(n log n)이다.

**오답 포인트**

- O를 “항상 최악의 경우”라는 뜻으로 정의하지 않는다. O는 상한 표기이고 최악 분석과 자주 함께 쓰일 뿐이다.

### Q3. 재귀 함수의 종료 조건이 중요한 이유는?

**답변**

기저 조건이 문제 크기를 더 줄이지 않고 직접 답을 반환해야 하며, 재귀 단계는 반드시 기저 조건에 가까워져야 한다. 각 호출은 스택 프레임을 사용하므로 깊이가 크면 스택 오버플로가 날 수 있다.

**오답 포인트**

- 재귀가 반복문보다 본질적으로 빠르다고 가정하지 않는다.

## 2. 검색과 정렬

### Q4. 이진 탐색의 전제와 복잡도는?

**답변**

탐색 대상이 정렬되어 있고, 탐색 범위를 절반씩 좁힐 수 있어야 한다. 임의 접근 배열에서는 O(log n)이다. 중간 인덱스는 `low + (high - low) / 2`로 계산하면 덧셈 오버플로 위험을 줄일 수 있다.

**오답 포인트**

- 연결 리스트도 논리적으로 절반을 나눌 수 있지만 중간 이동 비용 때문에 일반적인 이진 탐색의 O(log n) 이점을 얻지 못한다.

### Q5. 안정 정렬이란?

**답변**

비교 결과가 같은 원소들의 기존 상대 순서를 유지하는 정렬이다. 여러 키를 단계적으로 정렬하거나 표시 순서를 유지해야 할 때 유용하다.

**오답 포인트**

- 안정성은 결과가 “정확하다”는 뜻이 아니다.

### Q6. 삽입 정렬은 언제 유용한가?

**답변**

평균·최악은 O(n²)이지만 거의 정렬된 작은 데이터에서는 이동이 적고 구현이 단순하며 추가 메모리가 거의 없다. 고성능 혼합 정렬의 작은 구간 처리에도 쓰인다.

**오답 포인트**

- O(n²)이라는 이유만으로 모든 상황에서 쓸모없다고 하지 않는다.

### Q7. 퀵 정렬과 병합 정렬의 차이는?

**답변**

퀵 정렬은 피벗 기준 분할 후 재귀 정렬하며 평균 O(n log n), 나쁜 분할에서 O(n²)이다. 배열에서 캐시 효율이 좋고 제자리 구현이 가능하다. 병합 정렬은 항상 O(n log n), 안정 정렬이 가능하지만 배열에서는 보통 O(n) 보조 공간이 필요하다.

**오답 포인트**

- 실제 표준 `std::sort`를 순수 퀵 정렬이라고 단정하지 않는다. 일반적으로 introsort 계열로 최악 성능을 방어한다.

### Q8. 힙 정렬의 특징은?

**답변**

힙 구성 후 최댓값 또는 최솟값을 반복 제거한다. 시간은 O(n log n), 추가 공간은 O(1)로 구현할 수 있고 최악 시간도 보장하지만 일반적으로 불안정하며 캐시 효율이 퀵 정렬보다 불리할 수 있다.

**오답 포인트**

- 힙 구성은 반복 삽입이면 O(n log n)이지만 bottom-up heapify는 O(n)이다.

## 3. 그래프 탐색과 경로 찾기

### Q9. DFS와 BFS의 차이는?

**답변**

DFS는 스택 또는 재귀로 한 경로를 깊게 탐색해 백트래킹, 연결 요소, 사이클 검사에 적합하다. BFS는 큐로 거리 순서대로 탐색하며 가중치가 없는 그래프에서 간선 수 기준 최단 경로를 구한다. 둘 다 인접 리스트에서 O(V+E)다.

**오답 포인트**

- BFS가 모든 그래프의 최단 경로를 구하는 것은 아니다. 가중치가 다르면 다익스트라나 다른 알고리즘이 필요하다.

### Q10. 방문 배열은 언제 표시해야 하는가?

**답변**

BFS에서는 보통 큐에 넣는 순간 방문 처리해 같은 정점이 여러 번 큐에 들어가는 것을 막는다. DFS도 재방문이 가능한 그래프에서는 진입 시 표시한다.

**오답 포인트**

- 큐에서 꺼낼 때만 방문 처리하면 중복 삽입으로 시간·메모리가 크게 늘 수 있다.

### Q11. A*는 어떤 값을 기준으로 탐색하는가?

**답변**

시작점부터 현재까지 실제 비용 `g(n)`과 목표까지의 추정 비용 `h(n)`을 더한 `f(n)=g(n)+h(n)`이 작은 후보를 우선한다. 휴리스틱이 실제 남은 비용을 넘지 않는 admissible 조건이면 최적 경로를 보장할 수 있다.

**오답 포인트**

- 휴리스틱이 클수록 무조건 좋은 것이 아니다. 과대평가하면 최적성 보장을 잃을 수 있다.

### Q12. 맨해튼 거리와 유클리드 거리는 언제 쓰는가?

**답변**

상하좌우 격자 이동이면 맨해튼 거리, 임의 방향 직선 이동이면 유클리드 거리가 자연스럽다. 대각 이동 비용과 장애물 규칙에 따라 휴리스틱을 맞춰야 한다.

**오답 포인트**

- 이동 모델과 맞지 않는 휴리스틱을 무조건 사용하지 않는다.

## 4. 게임에서 자주 쓰는 알고리즘

### Q13. 쿼드 트리는 무엇인가?

**답변**

2차원 공간을 필요에 따라 네 구역으로 재귀 분할하는 공간 자료구조다. 넓은 월드에서 충돌 후보, 가시성, 근접 객체를 좁히는 broad phase에 유용하다.

**오답 포인트**

- 모든 데이터 분포에서 효율적인 것은 아니다. 객체가 경계에 걸치거나 한 구역에 몰리면 중복 저장·편향 문제가 생긴다.

### Q14. 선형 보간(LERP)은 무엇인가?

**답변**

`a + t(b-a)`로 두 값 사이를 보간한다. `t`가 0이면 a, 1이면 b다. 매 프레임 현재값에서 목표값으로 같은 비율을 보간하면 총 시간이 고정된 선형 이동이 아니라 지수적으로 접근하는 감쇠가 된다.

**오답 포인트**

- `current = lerp(current, target, speed * dt)`를 일정 속도 이동이라고 설명하지 않는다.

### Q15. 베지어 곡선은 어떻게 만들어지는가?

**답변**

제어점 사이의 반복 선형 보간으로 곡선을 만든다. 곡선은 일반적으로 중간 제어점을 통과하지 않고 그 방향과 형태의 영향을 받는다. 드 카스텔조 알고리즘으로 안정적으로 계산할 수 있다.

**오답 포인트**

- 매개변수 t가 같은 간격으로 증가해도 이동 거리가 일정하다고 가정하지 않는다. 일정 속도에는 호 길이 재매개화가 필요하다.

### Q16. 브루트 포스는 나쁜 알고리즘인가?

**답변**

가능한 후보를 모두 확인하는 접근이다. 입력이 작거나 정답 검증 기준을 만들 때, 최적화된 알고리즘의 비교 기준이 필요할 때 유용하다. 문제 크기와 제한을 계산해 허용 가능한지 판단한다.

**오답 포인트**

- 단순하다는 이유만으로 틀린 해법은 아니다. 정확성과 제한 내 성능이 기준이다.
