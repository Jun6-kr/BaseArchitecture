# 30일 학습 커리큘럼

기초 개념을 **설명 → 코드·도식 적용 → 인출 연습 → 오답 기록** 순서로 반복하는 30일 과정입니다. 하루 권장 시간은 60~90분이며, 상세 수업 파일은 실제로 학습하는 날에 하나씩 추가합니다.

## 진행 규칙

1. 사전 질문에는 자료를 보지 않고 먼저 답한다.
2. 핵심 개념을 학습한 뒤 코드 또는 손그림으로 직접 재현한다.
3. 마무리 질문은 30~60초 면접 답변으로 말한다.
4. 틀린 내용은 [`wrong-answer-log.md`](../wrong-answer-log.md)에 기록한다.
5. 다음 날 시작 전에 전날 내용을 5분 동안 복습한다.
