# BaseArchitecture

CS, C++, 자료구조, 알고리즘, 게임 프로그래밍 패턴을 꾸준히 복습하기 위한 학습 저장소입니다.

각 노트는 다음 세 가지를 함께 기록합니다.

- **질문**: 면접이나 복습 때 바로 꺼내 볼 수 있는 질문
- **답변**: 핵심 개념, 동작 원리, 선택 기준
- **오답 포인트**: 자주 빠뜨리는 조건과 부정확한 표현

## 권장 복습 방법

1. 질문만 읽고 30~60초 동안 소리 내어 답한다.
2. 답변과 비교해 빠뜨린 **조건**, **복잡도**, **트레이드오프**를 찾는다.
3. 틀린 항목은 오답노트에 날짜와 함께 기록한다.
4. 1일, 7일, 30일 뒤 다시 답하고 상태를 갱신한다.
